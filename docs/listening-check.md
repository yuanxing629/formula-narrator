## 1. 六类结构模板句（用示例公式实测文本）

### 分式
- [ ] F1 骨架：分式：分子两项，中间用加减号连接，分母是二a，含一个根号。
- [ ] F2 局部：分子是一个两项的式子，中间用加减号连接，含一个根号，含一个平方项；分母是二a。
- [ ] F3 细节：分子为 负 b 加减 根号下 b 的平方 减 四ac（即判别式），分母为 二a
- [ ] F4 口语化：n 的平方分之一（1/n²）
- [ ] F5 口语化：三分之二x（2x/3）

### 根号
- [ ] R1 骨架：一个根号，里面是两项，含一个平方项。
- [ ] R2 骨架（带指数）：一个三次根号，里面是两项。
- [ ] R3 局部：根号内是一个两项的式子，含一个平方项。
- [ ] R4 细节：根号下 b 的平方 减 四ac（即判别式）
- [ ] R5 细节（三次）：三次根号下 a 的立方 加 b 的立方

### 上下标
- [ ] P1 骨架：x 的 n 次方。
- [ ] P2 骨架：a 下标 i。
- [ ] P3 局部：底数是x，指数是n。
- [ ] P4 细节：x 的平方
- [ ] P5 细节：圆周率 的平方

### 求和/积分
- [ ] B1 骨架：一个求和：变量 i，从 一 到 n，求和项是i 的平方。
- [ ] B2 局部：下限 i 等于 一，上限 n，求和项是i 的平方。
- [ ] B3 细节：i 从 一 到 n，对 i 的平方 求和
- [ ] B4 细节（积分）：x 从 零 到 一，对 二x 积分
- [ ] B5 细节（无穷上限）：n 从 一 到 无穷，对 n 的平方分之一 求和

### 矩阵（重点：行 háng）
- [ ] M1 骨架：一个两行两列矩阵。
- [ ] M2 局部：第一行两个元素；第二行两个元素。
- [ ] M3 细节：两行两列矩阵：第一行 一，二；第二行 三，四
- [ ] M4 整式骨架：等式：左边A，右边一个两行两列矩阵。
- [ ] M5 整式局部：左边是A；右边是一个两行两列矩阵。
- [ ] M6 矩阵乘法细节：两行两列矩阵：第一行 一，二；第二行 三，四 乘以 两行两列矩阵：第一行 零，一；第二行 一，零 等于 两行两列矩阵：第一行 二，一；第二行 四，三

### 分段函数
- [ ] C1 骨架：分段表达式，共两种情况，每种带一个条件。
- [ ] C2 局部：第一种：条件 x 大于等于 零，值是x 的平方；第二种：条件 x 小于 零，值是负 x。
- [ ] C3 细节：分段表达式：当 x 大于等于 零 时，值为 x 的平方；当 x 小于 零 时，值为 负 x

## 2. 整式骨架/局部（规模与地标措辞）

- [ ] S1 等式：左边x，右边一个分式；含一个根号。
- [ ] S2 等式：左边两项，含两个平方项，右边c 的平方。
- [ ] S3 等式：左边两个两行两列矩阵相乘，右边一个两行两列矩阵。
- [ ] S4 等式：左边f x，右边一个两段分段表达式。
- [ ] S5 等式：左边一个求和，右边一个分式。
- [ ] S6 左边是一个两项的式子，含两个平方项；右边是c 的平方。
- [ ] S7 共两项：负 b；一个根号，中间用加减号连接。

## 3. 五条实测公式的完整三层（与 check:parser 输出一致）

### 求根公式
- [ ] Q1 骨架：等式：左边x，右边一个分式；含一个根号。
- [ ] Q2 局部：左边是x；右边是一个分式，分子两项（中间用加减号连接）、分母一项。
- [ ] Q3 细节：x 等于 分子为 负 b 加减 根号下 b 的平方 减 四ac（即判别式），分母为 二a

### 勾股定理
- [ ] Q4 骨架：等式：左边两项，含两个平方项，右边c 的平方。
- [ ] Q5 局部：左边是一个两项的式子，含两个平方项；右边是c 的平方。
- [ ] Q6 细节：a 的平方 加 b 的平方 等于 c 的平方

### 2×2 矩阵乘法
- [ ] Q7 骨架：等式：左边两个两行两列矩阵相乘，右边一个两行两列矩阵。
- [ ] Q8 局部：左边是两个两行两列矩阵相乘；右边是一个两行两列矩阵。
- [ ] Q9 细节：见 M6。

### 分段函数
- [ ] Q10 骨架：等式：左边f x，右边一个两段分段表达式。
- [ ] Q11 局部：左边是f x；右边是一个两段分段表达式。
- [ ] Q12 细节：f x 等于 分段表达式：当 x 大于等于 零 时，值为 x 的平方；当 x 小于 零 时，值为 负 x

### 巴塞尔级数
- [ ] Q13 骨架：等式：左边一个求和，右边一个分式。
- [ ] Q14 局部：左边是一个求和；右边是一个分式，分子一项、分母一项。
- [ ] Q15 细节：n 从 一 到 无穷，对 n 的平方分之一 求和 等于 分子为 圆周率 的平方，分母为 六

## 4. 降级与边界

- [ ] D1 白名单外符号：根号下 foo 一 加 二（\foo 念符号名，不整段失败）
- [ ] D2 角落提示文案：有 1 个符号未能朗读。（界面文案，保留阿拉伯数字）
- [ ] D3 显式乘号：二 乘以 三（数字×数字读「乘以」）
- [ ] D4 函数应用：正弦x（不插乘）；正弦 的平方x
- [ ] D5 括号：f x（函数调用不读括号）；左括号 a 加 b 右括号 c（优先级括号仍读）
