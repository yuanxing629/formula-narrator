## 1. 六类结构模板句（用示例公式实测文本）

### 分式
- [ ] F1 骨架：分式：分子 3 项、分母单项 2a，含 1 个根号。
- [ ] F2 局部：分子是一个 3 项式，含 1 个根号，含 1 个平方项；分母是单项 2a。
- [ ] F3 细节：分式：分子为 负 b 加减 根号下 b 的平方 减 4ac（即判别式），分母为 2a

### 根号
- [ ] R1 骨架：一个根号，里面是2 项，含 1 个平方项。
- [ ] R2 骨架（带指数）：一个 3 次根号，里面是2 项。
- [ ] R3 局部：根号内是一个 2 项式，含 1 个平方项。
- [ ] R4 细节：根号下 b 的平方 减 4ac（即判别式）
- [ ] R5 细节（三次）：3 次根号下 a 的立方 加 b 的立方

### 上下标
- [ ] P1 骨架：x 的 n 次方。
- [ ] P2 骨架：a 下标 i。
- [ ] P3 局部：底数 x，指数 单项 n。
- [ ] P4 细节：x 的平方
- [ ] P5 细节：圆周率 的平方

### 求和/积分
- [ ] B1 骨架：一个求和：变量 i，从 1 到 n，求和项是一个幂。
- [ ] B2 局部：下限 i 等于 1，上限 n，求和项是一个幂。
- [ ] B3 细节：对 i 的平方 从 1 到 n 求和（变量 i）
- [ ] B4 细节（积分）：对 2x 从 0 到 1 积分（微分变量 x）
- [ ] B5 细节（无穷上限）：对 分式：分子为 1，分母为 n 的平方 从 1 到 无穷 求和（变量 n）

### 矩阵（重点：行 háng）
- [ ] M1 骨架：一个 2 行 2 列矩阵。
- [ ] M2 局部：第 1 行 2 个元素；第 2 行 2 个元素。
- [ ] M3 细节：2 行 2 列矩阵：第 1 行 1，2；第 2 行 3，4
- [ ] M4 整式骨架：等式：左边单项 A，右边一个 2 行 2 列矩阵。
- [ ] M5 整式局部：左边是单项 A；右边是一个 2 行 2 列矩阵。
- [ ] M6 矩阵乘法细节：2 行 2 列矩阵：第 1 行 1，2；第 2 行 3，4 2 行 2 列矩阵：第 1 行 0，1；第 2 行 1，0 等于 2 行 2 列矩阵：第 1 行 2，1；第 2 行 4，3

### 分段函数
- [ ] C1 骨架：分段表达式，共 2 种情况，每种带一个条件。
- [ ] C2 局部：第 1 种：条件 x 大于等于 0，值是一个幂；第 2 种：条件 x 小于 0，值是单项 负 x。
- [ ] C3 细节：分段表达式：当 x 大于等于 0 时，值为 x 的平方；当 x 小于 0 时，值为 负 x

- [ ] S5 等式：左边一个求和，右边一个分式。
