## 三、抽样三层文本（C01 / C10 / C16 / C19 / C29）

### C01（代数，分式+根号+加减号）

```latex
x=\frac{-b\pm\sqrt{b^{2}-4ac}}{2a}
```

- 骨架：等式：左边x，右边一个分式；含一个根号。
- 局部：左边是x；右边是一个分式，分子两项（中间用加减号连接）、分母一项。
- 细节：x 等于 分子为 负 b 加减 根号下 b 的平方 减 四ac（即判别式），分母为 二a

### C10（微积分，定积分+微分）

```latex
\int_{0}^{1}x^{2}\,dx=\frac{1}{3}
```

- 骨架：等式：左边一个积分，右边一个分式。
- 局部：左边是一个积分；右边是一个分式，分子一项、分母一项。
- 细节：x 从 零 到 一，对 x 的平方 积分 等于 三分之一

### C16（线代，矩阵乘法）

```latex
\begin{pmatrix}1 & 2\\ 3 & 4\end{pmatrix}\begin{pmatrix}x\\ y\end{pmatrix}=\begin{pmatrix}x+2y\\ 3x+4y\end{pmatrix}
```

- 骨架：等式：左边一个两行两列矩阵 乘以 一个两行一列矩阵，右边一个两行一列矩阵。
- 局部：左边是一个两行两列矩阵 乘以 一个两行一列矩阵；右边是一个两行一列矩阵。
- 细节：两行两列矩阵：第一行 一，二；第二行 三，四 乘以 两行一列矩阵：第一行 x；第二行 y 等于 两行一列矩阵：第一行 x 加 二y；第二行 三x 加 四y

### C19（概率，贝叶斯）

```latex
P(A|B)=\frac{P(B|A)P(A)}{P(B)}
```

- 骨架：等式：左边一项，右边一个分式。
- 局部：左边是P左括号 A 竖线 B 右括号；右边是一个分式，分子一项、分母一项。
- 细节：P左括号 A 竖线 B 右括号 等于 分子为 P左括号 B 竖线 A 右括号 P左括号 A 右括号，分母为 P左括号 B 右括号

### C29（分段，三段）

```latex
f(x)=\begin{cases}1, & x>0\\ 0, & x=0\\ -1, & x<0\end{cases}
```

- 骨架：等式：左边一项，右边一个三段分段表达式。
- 局部：左边是f x；右边是一个三段分段表达式。
- 细节：f x 等于 分段表达式：当 x 大于 零 时，值为 一；当 x 等于 零 时，值为 零；当 x 小于 零 时，值为 负 一

## 四、降级演示（白名单外命令不整段失败）

以下 3 条公式展示白名单外命令的降级。字体命令与 operatorname（\text、\mathrm、\operatorname 等）自 S3 起读参数原文；
其余带参命令（\binom、\hat / \bar / \vec 等修饰符，见解析器 ARITY 表）
解析时按参数个数吞掉紧邻参数组，整体作为一个原子朗读为「未支持的符号」，并计入 unknown 计数；
不再把参数误读成独立因子（旧版 \binom{n}{k} 曾读成「n 乘以 k」，已修复）。
无参的白名单外命令仍降级念符号名。页面右下角出现提示「有 N 个符号未能朗读」（role="status"，读屏可感知）。
原子保留原源码供 KaTeX 渲染，公式显示不受影响（已实测无错误色）。

## 五、局限（如实声明）

- 只支持 6 类结构：分式、根号、上下标、求和/积分（含上下限）、矩阵、分段函数；不代表任意 LaTeX。
- 白名单外带参命令（\binom、\hat / \bar / \vec 等修饰符）整体读作「未支持的符号」，参数不朗读，计入角落提示。
- 字体命令与 operatorname 读参数原文（S3，2026-11-18）；参数内嵌数学命令（如 \text{\alpha}）降级回「未支持的符号」。
- 希腊字母与纯字母字面量后接括号按函数应用静默（S3 惯例）；拉丁字母×括号仍按乘积，\pi(r+1) 这类希腊乘积记法会被误读为应用。
- 换底对数读法已修复（S1，2026-11-18）：C24 细节层现读作「以 a 为底 b 的对数 等于 分子为 以 c 为底 b 的对数，分母为 以 c 为底 a 的对数」，
  不再出现「下标 ab」粘连。
- 语法错误（如缺右括号、带参命令缺参数）仍整段报错，属预期行为。
