# 公式旁白 · 朗读规则（rules.md）

> M1 修订版，**待产品负责人审核**；审核通过后才进入 M2。
> 模板与 `src/lib/narrate.ts` 一一对应；`{…}` 为子结构槽位。
> 本文档分三部分：**一、模板表**（每层模板 + 服务的任务）；**二、分派规则**（跨结构的调度逻辑）；**三、全局约束**（措辞与容错）。另附 **渲染映射**（第八节技术验证结论，供 M2 使用）。
> **ClearSpeak 对照列全部为「示意，未逐字核对」**：未接入 MathJax accessibility 实测（本项目不引入 SRE/MathCAT 依赖），仅凭规范常识书写，供评审参考，不作为正确性依据。

## 〇、层级模型与解析器约定

### 层级模型（本次修订核心）

接口：`narrate(node, level)`，`level ∈ {0,1,2}`。**任意节点**（不只是整式）都能独立产出三层文本；整式只是根节点。

| 层 | 定义 | 禁止 |
| --- | --- | --- |
| L0 骨架 | 结构 + 规模 + 地标：这是什么结构、多大（几项/几行几列/几段）、内含哪些结构地标（只报种类与数量） | 同义反复（如「分式由分子分母组成」）；读叶子数值内容 |
| L1 局部 | 只读**直接子结构**，每个子结构「是什么」（类型 + 自身直接规模） | 读孙节点内容（如分子层不得读「b 的平方」）；读兄弟分支的内容 |
| L2 细节 | **被点名的那一支**读到叶子 | 替其他分支读内容 |
| L3 从头读 | 独立的顺序朗读动作：从当前节点起逐字读完整子树，可暂停、可跳回 | 不是 L2 的别名；M2+ 实现为播放动作，不在三层文本面板内 |

- 已删除旧模型的 shallow/linear 两档与「sqrt/scripts 始终展开」规则——深度折叠会让局部层把整式读完（粒度塌陷），退化成 ClearSpeak 的 verbosity。
- 三层是**同一节点的三种粒度**，不是全局「简/中/详」档位（AGENTS 明令禁止）。
- 长度关系：L0 < L1 < L2 在分式、根号等结构节点上强制成立并有自检；整式等式允许例外——L1 含结构描述词（「是一个…项式」）可能长于纯读法的 L2（如勾股定理 24/27/22），已记录于实测报告。

### 解析器约定

- KaTeX 无稳定公开 AST（仅内部 `__parse`，@types/katex 无声明）→ 自写递归下降解析器，只覆盖 6 类结构 + 原子。
- 节点类型：`row`、`atom`、`group`、`frac`、`sqrt`（可带指数）、`scripts`、`bigop`（sum/int/prod/lim）、`matrix`（matrix/pmatrix/bmatrix/Bmatrix/vmatrix/Vmatrix）、`cases`。
- 节点 id 为路径串（根 `0`，子 `0.1`、`0.1.0`…），供 M2 点选寻址与 M3 展开记忆；渲染映射见文末。
- 容错：白名单外命令降级为原子（念符号名）并计数，页面角落提示「有 n 个符号未能朗读」；只有语法错误（括号/环境不匹配等）才整段报错。详见全局约束 G3。
- 自检：`npm run check:parser`（84 项断言）。

## 一、模板表

「服务的任务」列：①这是什么（L0）②找某一项（L1）③抄下来（L2/L3）④比较两式（M4，消费 L0/L1 的结构与规模描述）。无任务归属的层已删除。

### 1.1 分式 frac

| 层 | 模板 | 服务的任务 | ClearSpeak 参考（示意，未逐字核对） |
| --- | --- | --- | --- |
| L0 | 分式：分子 {项数} 项、分母{规模(分母)}，{地标}。 | ①这是什么 ④比较两式 | （无对应层，ClearSpeak 一次性线性读） |
| L1 | 分子是{描述(分子)}；分母是{描述(分母)}。 | ②找某一项 | the fraction with numerator … and denominator … |
| L2 | 分式：分子为 {逐字(分子)}，分母为 {逐字(分母)}。 | ③抄下来 | 同上（逐字） |

实例（求根公式的分式节点）：
- L0：分式：分子 3 项、分母单项 2a，含 1 个根号。
- L1：分子是一个 3 项式，含 1 个根号，含 1 个平方项；分母是单项 2a。
- L2：分式：分子为 负 b 加减 根号下 b 的平方 减 4ac（即判别式），分母为 2a

### 1.2 根号 sqrt

| 层 | 模板 | 服务的任务 | ClearSpeak 参考（示意，未逐字核对） |
| --- | --- | --- | --- |
| L0 | 一个{ n 次}根号，里面是{规模(被开方式)}。 | ①这是什么 ④比较两式 | （无对应层） |
| L1 | 根号内是{描述(被开方式)}。 | ②找某一项 | the square root of … / the cube root of … |
| L2 | {n 次}根号下 {逐字(被开方式)}{（即判别式）} | ③抄下来 | 同上（逐字） |

- 骨架给**规模 + 地标**而非空话：如「一个根号，里面是2 项，含 1 个平方项」。
- 被开方式为 b²−4ac 模式时 L2 追加「（即判别式）」语义标注。

### 1.3 上下标 scripts

| 层 | 模板 | 服务的任务 | ClearSpeak 参考（示意，未逐字核对） |
| --- | --- | --- | --- |
| L0 | {底数} 的{平方/立方/ n 次方}{ 下标 …}。 | ①这是什么（直接给读法，不上语法课） | x squared / x to the n-th power / x sub i |
| L1 | 底数 {描述}，指数 {描述}{，下标 {描述}}。 | ②找某一项 | （无对应层） |
| L2 | {底数} 的{平方/立方/… 次方}{ 下标 …} | ③抄下来 | 同左 |

- 骨架即读法（「x 的 n 次方」「a 下标 i」），不再说「这是一个上下标结构」。
- 指数特例：2→平方、3→立方，其余「… 次方」。

### 1.4 求和/积分/连乘/极限 bigop

| 层 | 模板 | 服务的任务 | ClearSpeak 参考（示意，未逐字核对） |
| --- | --- | --- | --- |
| L0 | 一个{求和/积分/连乘/极限}：变量 {v}，从 {下限值} 到 {上限}，{求和项/被积式/表达式}是{规模(主体)}。 | ①这是什么 ④比较两式 | （无对应层） |
| L1 | 下限 {逐字}，上限 {逐字}，{求和项/被积式}是{描述(主体)}。 | ②找某一项 | the sum from i equals 1 to n of … |
| L2 | 对 {主体} 从 {下限值} 到 {上限} 求和（变量 {v}）/ 对 {主体'} 从 … 积分（微分变量 {x}） | ③抄下来 | the integral from 0 to 1 of … d x |

- 变量抽取：下限 `i=1` 剥离出变量 i、下限值 1；`x\to 0` 同理；积分变量从被积式末尾 `d⟨字母⟩` 抽取（该 d⟨字母⟩ 不再读进主体）。
- 统一口语语序「对 f 从 0 到 1 积分」，上下限先于动作名。

### 1.6 分段函数 cases

| 层 | 模板 | 服务的任务 | ClearSpeak 参考（示意，未逐字核对） |

## 二、分派规则（跨结构调度，不属于任何单一模板）

- **D1 单一结构委托**：row 只含一个子节点时，三层均委托该子结构的对应层（整式 `x^{2}` 的骨架就是「x 的平方。」）。
- **D2 缺项省略**：scripts 无下标不提下标；bigop 无上/下限省略对应短语；cases 某段无条件省略「当…时」。
- **D3 两套句式**：含 `=` 的 row 用等式句式（左右分述）；否则用表达式句式（规模 + 项列表）。
- **D4 项的切分**：按二元 `+`/`-` 切项；行首或连接符后的符号为一元「负/正」；`\pm`/`\mp` 作为连接符单独成项（故求根公式分子 = 负 b、加减号、根号，共 3 项）。
- **D5 排版符号不朗读**：cases 值行末尾的 `,`/`;` 是 LaTeX 排版分隔符，L1/L2 均剥离。
- **D6 地标去重**：等式 L0 句尾地标只报左右规模描述中**未出现过**的结构种类（矩阵乘法等式不再重复「含 3 个矩阵」）。
- **D7 描述函数 descriptor**（L1 专用）：单项读内容；单一结构给类型 + 自身直接规模（分式报分子分母项数）；多项式给「一个 n 项式」+ 结构地标 + 平方项数。**绝不递归读孙节点内容。**
- **D8 规模函数 scale**（L0 专用）：单项读内容（作为地标）；单一结构给短类型；否则「n 项」+ 地标。

## 三、全局约束

### G1 TTS 友好措辞：多音字规避

- 朗读模板不得用孤立单字的多音字充当运算符或术语；一律改用词典词，让 TTS 按整词注音。Web Speech API 无 SSML/拼音注音，只能文案层规避。
- 案例：「乘」chéng/shèng，在「4 乘 a」语境误读 shèng（2026-11-17 实测）→ 统一「乘以」；「相乘」本身是词典词，保留。
- **多音字监测清单**（模板定稿与人工听检时逐词排查）：
  | 字 | 风险读音 | 规避措施 |
  | --- | --- | --- |
  | 乘 | shèng | 一律「乘以」；隐式乘法默认不读（G2） |
  | 行 | xíng | 矩阵「第 n 行」应读 háng；无法注音，列入 listening-check.md 人工听检 |
  | 差 | chà/chāi | 不单独用「差」，需要时说「相差」或改写 |
  | 重 | zhòng/chóng | 不用「重」，改「重复」等词典词 |
  | 数 | shù/shǔ | 「系数」「项数」等词典词内安全；孤立「数」避免 |
  | 角 | jiǎo/jué | 「角」几何语境读 jiǎo，列入听检 |
- 全部模板句的人工听检清单见 `docs/listening-check.md`。

### G2 隐式乘法默认静默

- `2a`→「2a」、`4ac`→「4ac」、`n(n+1)`→「n左括号 n 加 1 右括号」，不插任何乘词。
- 仅两种情况读「乘以」：数字×数字（`2\times3` 或相邻数字）、显式 `\times`/`\cdot`。
- 函数应用不插乘：f/g/h/sin/cos/tan/log/ln/exp（含 `\sin^{2}` 这类带指数底数）后接字母或左括号视为函数应用。
- 验收：6 条示例三层文本中「乘以」出现次数为 0（自检断言）。

### G3 符号白名单与降级

- 白名单约 80 个常用命令（希腊字母、关系符、集合符、逻辑符、函数名、省略号等），见 `src/lib/parser.ts` 的 `SYMBOL_WHITELIST` 与 `narrate.ts` 的 `ATOM_READ`。
- 白名单外命令：解析为原子、念符号名（`\foo`→「foo」）、计入 unknown；页面角落提示「有 n 个符号未能朗读」。
- `\left`/`\right` 在词法层透明跳过。
- 只有语法错误（缺括号、环境不匹配、不支持的环境）才整段报错；降级不整段失败。

### G4 层级粒度约束

- L0 不读叶子数值内容（单项作为规模地标除外）；L1 不读孙节点内容；L2 只读被点名支。
- 结构节点三层长度单调（L0<L1<L2）有自检；整式等式的例外见「层级模型」说明。

### G5 语义标注

- b²−4ac 模式 → L2 追加「（即判别式）」；这是语义层，不是读音规则。

## 渲染映射（第八节验证结论，供 M2 使用）

**结论：可行。** KaTeX 的 `\htmlData` 能把节点 id 写进渲染 DOM，M2 点选寻址可直接复用。

- 验证方式：AST→LaTeX 时用 `\htmlData{node=0.1}{…}` 包裹每个子结构，KaTeX 渲染后检查 DOM。
- 必需选项：
  ```js
  katex.render(tex, el, {
    trust: (ctx) => ctx.command === '\\htmlData', // 只放行 htmlData，\href 等仍被拦截
    strict: 'ignore',                             // 否则 htmlData 触发 strict 警告
    output: 'htmlAndMathml',                      // 纯 MathML 输出会丢 data-node
    throwOnError: false,
  })
  ```
- 值**不要加引号**：`\htmlData{node="0.1"}` 会把引号转义进属性值（`data-node="&quot;0.1&quot;"`）；用 `\htmlData{node=0.1}`。
- 嵌套包裹时各层 id 均保留在 DOM（外层 `.katex-html` 子树可查到全部 `data-node`）。
- 开销：每个包裹约 68 字节额外 HTML；示例公式量级可忽略。
- M2 实现路径：解析树 → 带 `\htmlData` 包裹的 LaTeX → KaTeX 渲染 → 事件委托读 `closest('[data-node]')` → `findNode(tree, id)`。
