# M5 验收证据（evidence）

生成日期：2026-11-18。基线：commit 3057734（S3）。M5 代码改动仅三处：App.tsx 的 rootDetail 记忆化、StructureList.tsx 的路径与朗读标签记忆化、styles.css 在 ≤480px 时角落提示改静态布局；朗读引擎、差异算法、6 个预置示例语义零改动。
验证命令：`npx tsc -b`、`npm run check:parser`（780 条断言）、`npm run check:corpus`（30 条语料）；浏览器实测（Vite dev 与已发布公开站点）。

## 一、验收标准逐条实测（AGENTS.md §5）

1. **首屏默认示例、播放骨架两秒内出声、无登录无权限**：首屏预置一元二次方程求根公式；触发「播放骨架」后 `speechSynthesis.speaking === true`（立即发起朗读）；公开站点 access_mode=public，全程无登录、无权限请求。
2. **点选子结构 → 面包屑更新、只读该节点**：选中「根号」→ 面包屑「等式 › 右边 › 分式 › 分子 › 根号」，aria-live「已选中：根号」，朗读区标题「朗读区 · 等式 › 右边 › 分式 › 分子 › 根号」，三层文本仅含该节点；高亮 fn-selected=1、祖先虚线 fn-ancestor=3。
3. **展开/收起后返回上层仍停在上次位置**：收起「按结构点名」后点选「根号内」，列表保持收起（不自动弹开），面包屑正确到六级；重新展开恢复。面包屑点回「右边」→ aria-live「已选中：右边」，朗读区随路径更新。
4. **对比差异句一句话说完且正确**：钉住默认公式后把 `-b` 改为 `+b` → 差异卡「分子开头的减号变成了加号。」（符号翻转，一句话）；指数/系数/增删项覆盖见 M4 验收与 docs/rules.md 对照。
5. **语音降级完整可用**：删除 `window.speechSynthesis` 后点播放 → 横幅「此浏览器不支持语音，三层文本仍可正常阅读。」+ 提示「语音不可用，请直接阅读下方文本。」；三层文本、朗读稿 textarea、复制按钮全部在位（原文见 §2.3）。
6. **手机可用 / 键盘 Tab 走完主流程 / 200% 缩放不破版**：实测数值见 §2.1、§2.2。
7. **纯静态、运行时零第三方请求**：公开站点整页仅 4 个请求且全同源（index js、index css、2 个 KaTeX woff2 字体，全部本地打包）；dev 环境 27 个请求全为 localhost。无 CDN、无后端、无 key。

## 二、M5 专项实测

### 2.1 布局：移动 390px 与 200% 缩放等效 640px

方法：同域 iframe 承载真实窄视口（媒体查询真实生效）。200% 缩放等效原理：1280px 屏幕浏览器缩放 200% 后的布局 = 640 CSS px 视口布局。

| 视口 | 页面 scrollWidth / innerWidth | 横向溢出 | 公式区 client / scroll | 结论 |
| --- | --- | --- | --- | --- |
| 390×844（binom 例，含角落提示） | 371 / 386 | 无 | 297 / 297 | 不破版；角落提示已静态 |
| 390×844（26 项相加超宽式） | 371 / 386 | 无 | 297 / 937 | 超宽公式仅在渲染区内横向滚动 |
| 640×800（binom 与柯西-施瓦茨宽式） | 621 / 636 | 无 | 547 / 547 | 等效 1280 屏 200% 缩放，不破版 |

- tap 目标：按钮最小高度 40px；公式内小目标由 fn-tiny ::after 外扩热区（M2）。
- 本轮修复：≤480px 时 corner-note 由 fixed 改 static（`width: fit-content; margin-left: auto`），避免悬浮层盖住底部按钮 tap 热区；390px 实测 computed position=static。

### 2.2 键盘

- 焦点序（DOM 序，默认示例共 24 停）：6 个示例按钮 → LaTeX 输入框 → 面包屑 → 「按结构点名」summary → 8 个结构按钮 → 钉住对比 → 读这个节点 →（读整体在根节点禁用、跳过）→ 播放骨架 / 播放局部 / 播放细节 → 复制朗读稿 → 朗读稿 textarea。全部原生 button/textarea/summary，无自定义按键劫持、无焦点陷阱。
- KaTeX 视觉层可聚焦节点数 = 0（`.katex-html [tabindex]`），读屏走 MathML 与结构列表（M4.1）；结构按钮 aria-label = 面包屑路径 + 该节点局部朗读。
- focus-visible 描边实测 3px。
- 接线实测：结构按钮触发 → 选中/面包屑/高亮/朗读区全更新（§一.2）；面包屑触发回上层（§一.3）；播放触发发起语音（§一.1）。
- **实测方式声明**：本轮内嵌浏览器面板处于隐藏态，按键与鼠标事件管线不可用（Tab/Enter/工具 click 均送不进页面，visibilityState=hidden）；上述接线为脚本触发 click 的实测，「按键 → click 激活」属浏览器对原生 `<button>` 的内置语义。打开面板后的复测步骤：页首按 Tab 应依次落在「一元二次方程求根公式」…「朗读稿纯文本」24 停；在结构按钮上按 Enter 应更新面包屑与 aria-live。复测记录待补。

### 2.3 语音降级原文（删除 speechSynthesis 后实测）

- 横幅（role=status）：此浏览器不支持语音，三层文本仍可正常阅读。
- 点播放后提示（role=status）：语音不可用，请直接阅读下方文本。
- 三层文本在位（骨架/局部/细节各一段），朗读稿 textarea 原文开头：「骨架：等式：左边x，右边一个分式；含一个根号。\n局部：左边是x；右边是一个分式，分子两项（中间用加减号连接）、分母一项。」
- 「复制朗读稿」按钮在位；clipboard 不可用时回退 focus+select+execCommand，再失败提示手动复制（NarrationPanel）。

### 2.4 性能

- 探针（node + esbuild bundle，30 条语料）：parse + 三层朗读合计 **5.99ms**，单条最差 C01 **1.88ms**；热路径 C16（矩阵乘法）parse+L2 重复 100 次 **3.96ms**。
- M5 记忆化：rootDetail 与结构列表的路径/朗读标签只随结构树重算；点选切换、焦点变化不再重复跑 narrate。
- KaTeX renderToString 按树记忆化（M2）；高亮重绘只清上一轮再涂当前链与祖先链。
- 构建产物：index js 454.63 kB（gzip 141.05 kB）、index css 33.95 kB（gzip 9.43 kB）；KaTeX 字体本地 woff2/ttf，首屏仅按需加载 2 个 woff2。
